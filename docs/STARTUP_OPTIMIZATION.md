# 一期首屏与本机预设验证

日期：2026-11-18。

## 首屏资源

图片导出、配图计划与任务面板、X预览、语法参考和视频对比改为按需加载。飞书侧栏仅在本地账号功能启用且打开时加载。弹层工具加载时提供等待提示；加载失败可以关闭，正文继续保留。

同一项目在修改前后执行生产构建，统计入口JavaScript；gzip均使用Python gzip按level 9计算，单位为字节。修改后数据包含本机草稿备份功能。

| 指标 | 修改前 | 修改后 | 减少 |
| --- | ---: | ---: | ---: |
| 首屏JavaScript原始大小 | 955,240 | 784,739 | 17.8% |
| 首屏JavaScript gzip大小 | 308,369 | 263,513 | 14.5% |

浏览器确认首次进入排版页仅请求入口JavaScript，打开导出工具后才请求图片导出模块，视频路由也能正常按需加载。本轮不包含公网服务器更新或公网加载耗时复测，资源减少比例不能直接作为加载耗时改善比例。构建仍有入口包超过500kB的提示。

## 本机预设

顶部统一为“排版方案”入口，面板内分为“精选方案”和“我的方案”，复用已有自定义方案数据，不要求账号登录。通过浏览器验证18px字号配置保存、刷新恢复、重新应用、重命名、删除、JSON导出及再次导入；导入生成独立ID。错误JSON、浏览器写入失败和30套上限均不会覆盖原方案。桌面和390px手机界面截图已查看，手机无横向溢出。
