# 排版工作台个人API

更新：2026-11-15。

当前生产无需登录即可设置个人API；账号和会员服务端API暂未开放，本地开发身份不改变个人API的使用方式。工作台设置展示API Key、Base URL和模型，保存在当前浏览器的原有openai_api_key、openai_api_base、openai_model键中；不上传到账号数据库，不随登录或退出自动切换。共用设备请自行清空配置。

AI排版、封面方案及小红书图文生成直接请求用户填写的OpenAI兼容服务商。配图规划与渲染使用浏览器实现，结构化内容可调用个人API；当前场景图回退为信息图。个人密钥缺失或请求失败时，不自动使用平台密钥或额度。文章管理生产中仍为规划占位，服务器图片上传需要真实登录。

## 测试连接

AI设置中新增“测试连接”，使用当前输入的API Key、Base URL及模型发送一次简短的真实模型请求，无需先保存，也不写入配置。游客和登录用户均可测试。点击前说明可能消耗少量API额度，测试中防止重复提交。

有效的非空模型响应才显示测试通过和总响应耗时，HTTP 200但返回HTML或空内容不算成功。401、403、404、429和服务商异常分别给出提示；浏览器网络错误只提示检查网络、地址或跨域，不能据此断定具体网络原因。测试结果不展示密钥或服务商原始响应。

15秒超时。修改任何API字段、关闭设置或切换设置页签会取消当前测试并清除旧结果。失败不阻止保存，测试也不会回退平台API。开发模式沿用已有开发代理，生产由浏览器直接请求填写的服务商。

生产浏览器直连需要服务商支持CORS；HTTPS网站使用HTTPS接口。开发环境沿用已有同源开发代理。这里没有添加公网匿名转发任意URL的代理。
