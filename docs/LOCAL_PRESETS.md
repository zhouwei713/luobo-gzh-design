# 本机排版预设

外观工具栏统一使用“排版方案”入口，预览栏不再重复放置方案按钮。面板内“精选方案”提供六套内置组合，“我的方案”管理保存在当前浏览器的个人方案。无需登录即可保存当前主题、版式、图片风格、强调样式、字号、行距、边距和组件样式，已有方案继续保留。

支持命名保存、应用、编辑更新、另存为、改名、复制、排序、删除，以及JSON导入导出。每个浏览器最多保存30套，容量不足或浏览器写入失败会提示，原方案保留。导入文件不超过1MB。

预设只保存在当前浏览器，与账号、文章正文和API密钥分别存储。清理站点数据前请导出备份；换设备时可通过JSON文件迁移。导出文件不包含正文、API密钥或登录凭证。云端预设仍属于后续功能。
