# 本机草稿、历史备份与恢复

当前生产无需登录即可排版。正文停笔800毫秒后自动保存到当前浏览器；“草稿备份”提供独立的历史版本及文件迁移。两者均为本机数据，不会自动同步到其他设备，清理站点数据会丢失。

## 草稿备份

在Markdown编辑区顶部点击“草稿备份”：

- 立即备份：可填写名称，手动保存当前正文，连续相同内容不会重复保存。
- 自动历史：正文变化时每分钟保存一版，最多20版、约2MB；达到上限时淘汰最旧版本，重要版本请另行导出。
- 恢复：先选择“恢复此版本”，确认后才替换正文。恢复前正文会留在历史及撤销快照中，可通过AI工具菜单撤销。
- 删除：确认后仅删除选中的历史版本，当前正文不变。
- 导出全部备份：JSON中包含当前正文与历史，不包含API密钥、登录凭证或个人配置。
- 导入备份文件：仅加入历史列表，去重后保留原记录，用户明确恢复时才替换正文；容量不足会拒绝导入，不删除原历史。文件不能超过3MB。

恢复会先写入本机历史、正文及撤销快照，写入失败则回滚并保留当前编辑器内容。正文过大而无法留存恢复前版本时，先导出Markdown再操作。原有账号分区的本机稿和历史继续隔离，晚返回的旧身份操作会被拒绝。

历史损坏时不会自动覆盖记录，面板提供原始记录导出，方便自行保管及排查。浏览器完全不可用时，优先通过已有正文导出功能保存文件。

## 当前开放范围

登录、云端文章及自动跨设备同步尚未开放。本机排版方案通过顶部“排版方案”另行保存和导出，与正文备份分开，详见[本机方案](LOCAL_PRESETS.md)。

## 本地账号开发与旧稿兼容

以下为本地开发账号功能与旧版数据兼容规则，生产不开放登录或“保存文章”。

## 访客与旧版文章

旧版共用的正文和撤销快照继续作为访客草稿保留，不自动认领到新账号，也不进行数据库迁移。原存储键继续用于访客，避免复制大篇正文造成额外存储占用。

登录后，如本浏览器有实际访客草稿，编辑器会提示手动恢复。也可在“工作台设置 → 本机草稿恢复”点击“恢复访客草稿”。恢复时保留访客原稿，把当前账号正在编辑的正文存为撤销快照。需要回退时，在“AI工具”中选择“撤销：恢复访客草稿”。

“暂不带入”只关闭当前账号的自动提示，不删除访客正文；设置中的恢复入口仍可使用。恢复写入失败时回滚，不覆盖已保存的正文和快照。

## 保存与账号切换

- 停止输入800毫秒后自动保存；正常离开、刷新及账号切换时立即尝试保存最新正文。
- 编辑器始终绑定进入时的草稿归属，避免其他标签页切换账号后，把旧正文写入新账号。
- 登录过期会保留原账号的本机草稿，重新登录后可继续编辑。较晚返回的旧身份检查结果不会覆盖新会话。
- 存储失败时显示提示；主动离开或退出会先检查保存是否成功，失败时应先导出。浏览器崩溃、强制结束进程或存储被禁用时，无法保证最后一次未写入编辑的恢复。

本次不包含跨设备同步或同账号多标签页协同编辑。
