# 文章图片与失效图片替换

当前生产可检测图片并更换链接，无需登录；“上传原图到本站”暂未开放。下文登录上传及对应测试属于本地开发能力，不能作为生产开放说明。


在右侧“公众号”预览工具栏点击“文章图片”，可查看正文中可识别的Markdown图片及加载状态。

- 更换链接：输入完整HTTP或HTTPS图片地址，仅替换选定的一处图片。正文、代码示例中的相同URL不会一并替换。引用式图片会转成该处独立的内联图片，原引用定义及其他引用保留。
- 上传原图替换：真实登录后选择JPG、PNG、GIF、WebP或AVIF原图，最大10MB。通过本站上传接口保存原始文件，不进行二次压缩，保留GIF原文件。不同于编辑器原有上传模式，此操作明确上传到当前服务器，不使用旧Cloudflare地址或第三方图床配置。
- 替换前保留当前正文为撤销快照，可从“AI工具 → 撤销：替换文章图片”恢复。服务器文章仍需手动保存。
- 上传失败、本机写入失败、账号变化或上传期间正文变化时停止替换，不覆盖较新的正文。图片已上传但替换未成功时显示已上传地址供复用；不会自动删除已上传文件。

面板支持内联、常规引用式Markdown图片、括号URL和Windows换行，跳过代码块及行内代码。HTML图片和无法准确定位的复杂跨行语法暂不自动修改，可在正文中编辑。管理器使用既有Markdown解析器的图片规则定位，升级解析器时应保留对应回归检查。

“加载正常”只说明当前浏览器可以显示，不保证目标平台可加载或转存。面板中的外部图片会按原地址加载，不通过服务器代理任意URL。过期或需授权的外链不能凭空恢复，需要原图或新地址。localhost、内嵌和临时图片地址不能据此当作公网图床；目标Linux服务器域名与HTTPS部署后仍需验收外部访问及公众号实际粘贴。

原稿里的18张飞书失效链接未自动替换，本轮不改写用户原稿或伪造原图片。
